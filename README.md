# Aneela Iqbal — Portfolio Website

A stunning, international-level portfolio website built with pure HTML, CSS, and Vanilla JavaScript.

## ✨ Features

- 🌟 Cinematic dark luxury design
- ✨ Animated particle background (Canvas API)
- 🖱️ Custom magnetic cursor with lerp animation
- 📜 Scroll progress bar
- 🔤 Cormorant Garamond editorial typography
- 🎞️ Staggered hero entrance animations
- 📢 Infinite marquee ticker strip
- 📊 Animated skill bars (triggered on scroll)
- 💻 Live mock UI dashboard preview (PharmaCore AI)
- 🎯 Scroll-triggered reveal animations
- 📱 Fully responsive (mobile + tablet + desktop)
- 0️⃣ Zero dependencies — pure HTML/CSS/JS

## 🚀 Deployment (Vercel)

1. Extract the zip file
2. Go to [vercel.com](https://vercel.com) → New Project
3. Upload the `index.html` file OR drag the folder
4. Click **Deploy** — done!

OR push to GitHub and connect the repo to Vercel.
